# Connect Threatr to threat-intelligence vendors

This guide shows how to give Threatr the credentials of the external services it queries. Threatr only returns data from the vendors it has credentials for. The vendor identifiers and the credential formats are listed in [Vendors](/docs/reference/threatr/vendors).

In the Threatr administration panel, open the *Vendor Credentials* menu and create one entry per vendor:

<Tabs groupId="api-keys">

    <TabItem value="virustotal" label="VirusTotal">

Use the vendor identifier `vt` and set the credentials
  ```json
  {"api_key": "your API key"}
  ```

  </TabItem>
    <TabItem value="otx-alien-vault" label="OTX Alien Vault">

Use the vendor identifier `otx` and set the credentials
  ```json
  {"api_key": "your API key"}
  ```

  </TabItem>
    <TabItem value="shodan" label="Shodan">

Use the vendor identifier `shodan` and set the credentials
  ```json
  {"api_key": "your API key"}
  ```

  </TabItem>
    <TabItem value="scarlet-shark" label="Scarlet Shark">

Use the vendor identifier `scarlet_shark` and set the credentials
  ```json
  {"api_key": "your API key"}
  ```

  </TabItem>
    <TabItem value="misp" label="MISP">

Use the vendor identifier `misp` and set the credentials
  ```json
  {"api_key": "your API key", "url":"url of the MISP server"}
  ```

  </TabItem>

</Tabs>


## Spread the requests over several API keys

To use several API keys for the same vendor, add several *Vendor Credentials* with the same vendor identifier: Threatr uses them in turn. This does not apply to MISP.
