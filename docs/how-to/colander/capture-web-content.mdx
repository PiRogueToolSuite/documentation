# Capture web content

This guide shows how to capture web pages with the **Colander Companion** browser extension, and how to turn the captures stored in your **drop zone** into artifacts of a case.

Colander Companion captures a static rendering of a web page and sends it to your drop zone. The drop zone is a personal, temporary storage, where potential evidence waits until you sort it: each Colander user has their own. Other ways to add artifacts are described in [Add artifacts to a case](/docs/how-to/colander/add-artifacts).

:::caution[Requirements]

Colander Companion is compatible with Mozilla Firefox.

:::

## Capture a web page

* Web content acquisition can be initiated at any point during a browsing session by clicking the Colander Companion extension icon.
* A pre-capture prompt allows the user to designate a case for association, but this step is not mandatory.
* To finalize the capture, press the `Capture` button.

Depending on the richness of the web content, wait for the Colander Companion popup `Captured !`. You can then continue browsing: the capture is in your drop zone.

## Open your drop zone

When connected to your Colander account:
  1. Click on `Colander` header to go back to home page
  2. Select `Drops` menu entry

<CaptionedImage src="/img/colander/artifact_acquisition/colander-dropzone-location.png" alt="Drop zone location" caption="Drop zone location" align="center"/>

## Delete or review drops

In the drop zone, you process drops in batches: convert them to artifacts, or delete them.

:::caution

Deleting drops is destructive and cannot be undone.

:::

If the user chooses not to keep certain uploads, it proceeds as follow:

1. Select one or more dropped files to delete
2. Click `Delete` action

<CaptionedImage src="/img/colander/artifact_acquisition/colander-dropzone-delete.png" alt="Drop zone delete action" caption="Drop zone delete action" align="center"/>

If the user wants to keep files and associate them with a case, they're converted to Artifacts as follows:

1. Select one or more dropped files to review
2. Click `Review` action

<CaptionedImage src="/img/colander/artifact_acquisition/colander-dropzone-review.png" alt="Drop zone review action" caption="Drop zone review action" align="center"/>

## Convert drops into artifacts

The review process is a wizard devided into few steps.
Each step asks the user various Artifact properties to be applied to **all** selected reviewed drops.
The user can cancel the reviewing process at any point in the wizard.

The case association is an important step, as it can't be changed later. Take care if you review drops in batch.
<CaptionedImage src="/img/colander/artifact_acquisition/colander-dropzone-review-step-1.png" alt="Drop zone review wizard" caption="Drop zone review wizard" align="center"/>

In single drop review, the user can modify the `Name` of the destination Artifact.
In batch mode, the `Name` field keeps its original value, but the user can change it later in details of the artifact.
All other properties are applied to the whole batch.
<CaptionedImage src="/img/colander/artifact_acquisition/colander-dropzone-review-step-2.png" alt="Drop zone review wizard" caption="Drop zone review wizard" align="center"/>

The user can add attributes to Artifact at this step. All attribute values that are empty will be omitted.
<CaptionedImage src="/img/colander/artifact_acquisition/colander-dropzone-review-step-3.png" alt="Drop zone review wizard" caption="Drop zone review wizard" align="center"/>

Last, the user can provide a more detailed description.
Clicking `Convert` will validate and launch the conversion to Artifact.
<CaptionedImage src="/img/colander/artifact_acquisition/colander-dropzone-review-step-4.png" alt="Drop zone review wizard" caption="Drop zone review wizard" align="center"/>

After the conversion, Artifacts can be found in each destination case under details of the artifact.
