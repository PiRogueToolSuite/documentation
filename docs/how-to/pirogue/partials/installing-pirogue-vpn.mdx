
In this setup, the PiRogue is a server with a single network interface exposed on the internet, typically a dedicated server or a VPS. The devices you analyze connect to it through a VPN.


:::tip[Hosting providers compatibility]

* <span style={{color: '#41C067'}}>✔</span> [Hetzner](https://www.hetzner.com/)
* <span style={{color: '#41C067'}}>✔</span> [Scaleway](https://www.scaleway.com/)
* <span style={{color: '#EE5080'}}>✘</span> Digital Ocean (incompatible)

:::

You need a server running:

 - Debian 13, on a physical or virtual machine;
 - on the `amd64` or `arm64` architecture;
 - with at least 4 GB of RAM and 40 GB of disk;
 - with a working internet connection.

You also need:

 - a DNS record pointing to the public IP address of the server;
 - ports `80` and `443` of the public IP address forwarded to the same ports of the server.

With a single network interface, the PiRogue selects the *VPN* mode and sets up WireGuard automatically.

**1. Update the system.** This step is not specific to the PiRogue:

```shell {title="Make sure the system is up-to-date"}
sudo apt-get update
sudo apt-get dist-upgrade
```

**2. Add the PiRogue PPA and install the PiRogue packages:**

```shell {title="Configure the PiRogue PPA and install PiRogue packages"}
sudo apt-get install wget
sudo wget -O /etc/apt/sources.list.d/pirogue.list https://pts-project.org/debian-13/pirogue.list
sudo wget -O /etc/apt/trusted.gpg.d/pirogue.gpg   https://pts-project.org/debian-13/pirogue.gpg
sudo apt-get update
sudo apt-get install pirogue-base
```

If the installation asks whether non-superusers should be able to capture network traffic, answer `Yes`.

**3. Check the configuration.** You don't need to be `root` for this:

```shell
pirogue-admin-client system get-configuration
```

**4. Secure the dashboard with a TLS certificate.** The server is reachable from the internet, so the dashboard must use HTTPS. Replace the domain and the email address with your own:

```shell
pirogue-admin-client external-network enable-public-access --domain pirogue.example.org --email contact@example.org
```

The dashboard is then available at `https://pirogue.example.org/dashboard`.

**5. Connect a device to the VPN.** Create a VPN peer and display its configuration as a QR code:

```shell
pirogue-admin-client vpn add-peer
pirogue-admin-client vpn get-peer-config 2 | qrencode -t ANSIUTF8
```

On the phone to analyze, scan the QR code with the WireGuard app, then enable the VPN.
