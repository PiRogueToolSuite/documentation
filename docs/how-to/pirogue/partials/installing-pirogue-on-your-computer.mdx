
You need a machine with **two network interfaces**, running:

 - Debian 13, on a physical or virtual machine;
 - on the `amd64` or `arm64` architecture;
 - with at least 4 GB of RAM and 40 GB of disk;
 - with a working internet connection.

The second interface decides the operating mode of the PiRogue. If it is a Wi-Fi interface, the PiRogue uses the *access point* mode. If it is an Ethernet interface, it uses the *appliance* mode. See [Operating modes](/docs/explanation/pirogue/operating-modes).

**1. Update the system.** This step is not specific to the PiRogue:

```shell {title="Make sure the system is up-to-date"}
sudo apt-get update
sudo apt-get dist-upgrade
```

**2. Add the PiRogue PPA and install the PiRogue packages:**

```shell {title="Configure the PiRogue PPA and install PiRogue packages"}
sudo apt-get install wget
sudo wget -O /etc/apt/sources.list.d/pirogue.list https://pts-project.org/debian-13/pirogue.list
sudo wget -O /etc/apt/trusted.gpg.d/pirogue.gpg   https://pts-project.org/debian-13/pirogue.gpg
sudo apt-get update
sudo apt-get install pirogue-base
```

If the installation asks whether non-superusers should be able to capture network traffic, answer `Yes`.

**3. Check the configuration.** You don't need to be `root` for this:

```shell
pirogue-admin-client system get-configuration
```

The most important values are:

 - `SYSTEM_OPERATING_MODE`: the operating mode of the PiRogue.
 - `DASHBOARD_PASSWORD`: the password of the dashboard, generated during the installation.
 - `WIFI_PASSPHRASE`: the passphrase of the Wi-Fi network in *access point* mode, also generated during the installation.
 - `EXTERNAL_ADDRESS` and `SYSTEM_HOSTNAME`: where the dashboard is exposed.

**4. Open the dashboard** at `https://EXTERNAL_ADDRESS/dashboard` or `https://SYSTEM_HOSTNAME.local/dashboard`, replacing the names with the values from the previous step. Unless you [enable public external access](/docs/how-to/pirogue/configure-pirogue#make-the-pirogue-accessible-from-the-internet), you have to [trust the default self-signed certificate](https://pts-project.org/cookbooks/pirogue-trust-self-signed-certificate/) first.

To change the generated passwords, see [Configure a PiRogue](/docs/how-to/pirogue/configure-pirogue).

The *access point* and *appliance* modes differ in how the isolated network is provided. In *access point* mode, `hostapd` runs the Wi-Fi network. In *appliance* mode, it is not used.
