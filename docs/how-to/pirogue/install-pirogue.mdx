# Install a PiRogue

This guide shows how to install a PiRogue on a Raspberry Pi, on a computer with two network interfaces, or on a server used as a VPN. The setup you pick determines the [operating mode](/docs/explanation/pirogue/operating-modes) of the PiRogue. For a first, guided discovery, follow the tutorial [Your first PiRogue on a Raspberry Pi](/docs/tutorials/pirogue-on-a-raspberry-pi) instead.
