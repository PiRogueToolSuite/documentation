# Vendors

The external services Threatr can query. Credentials are stored in the *Vendor Credentials* menu of the Threatr administration panel, see [Connect Threatr to threat-intelligence vendors](/docs/how-to/threatr/connect-vendors).

| Vendor | Vendor identifier | Credentials | Several keys |
|--------|-------------------|-------------|--------------|
| VirusTotal | `vt` | `{"api_key": "your API key"}` | Yes, used in turn |
| OTX Alien Vault | `otx` | `{"api_key": "your API key"}` | Yes, used in turn |
| Shodan | `shodan` | `{"api_key": "your API key"}` | Yes, used in turn |
| Scarlet Shark | `scarlet_shark` | `{"api_key": "your API key"}` | Yes, used in turn |
| MISP | `misp` | `{"api_key": "your API key", "url": "url of the MISP server"}` | No |
