# Default configuration

## Version

The version of a PiRogue is the version of its package `pirogue-base`:

```shell title="PiRogue version 3.0.0 is installed"
$ dpkg -l | grep pirogue-base
ii  pirogue-base    3.0.0    all    Install all PiRogue packages
```

| Version | Debian |
|---------|--------|
| 3.x | Debian 13 (Trixie) |
| 2.x | Debian 12 (Bookworm) |

Versions `>=2.x` changed the dashboard and the Wi-Fi configuration, see [Changes in PiRogue 2.x](/docs/reference/pirogue/changes-in-2x). Versions `>=3.x` moved to Debian 13, see [Changes in PiRogue 3.x](/docs/reference/pirogue/changes-in-3x).

## Default configuration

| Name | PiRogue 2.x and 3.x | PiRogue 1.x |
|------|-------------|-------------|
| SSH port | `22` | `22` |
| SSH user | `pi` | `pi` |
| SSH password | `raspberry` (change it at the first login) | `raspberry` |
| Dashboard URL | `https://pirogue.local/dashboard`, with a self-signed certificate | `http://<PiRogue IP address>:3000` |
| Dashboard user | `admin` | `admin` |
| Dashboard password | randomly generated | `PiRogue` |
| Wi-Fi SSID | `PiRogue1` | `PiRogue1` |
| Wi-Fi password | randomly generated | `superlongkey` |

With PiRogue 2.x, retrieve the generated secrets on your PiRogue:

```bash title="PiRogue 2.x"
pirogue-admin-client wifi get-configuration
pirogue-admin-client dashboard get-configuration
```

With PiRogue 1.x, show the configuration with:

```bash title="PiRogue 1.x"
sudo pirogue-ctl config show
```

## Important files

| Name | Location |
|------|----------|
| SSH configuration | `/etc/ssh/sshd_config` |
| Suricata rules | `/var/lib/suricata/rules/suricata.rules` |
| PiRogue configuration (1.x) | `/var/lib/pirogue/config/pirogue.env` |
| PiRogue configuration (2.x) | `/var/lib/pirogue/admin/config.yaml` |

## Configuration variables

With PiRogue 2.x, `pirogue-admin-client system get-configuration` displays the configuration of the PiRogue:

```txt title="Example of configuration"
DASHBOARD_PASSWORD: PiRogue
ENABLE_DHCP: 'True'
ENABLE_PUBLIC_ACCESS: 'False'
EXTERNAL_ADDRESS: 192.168.1.37
EXTERNAL_INTERFACE: enp0s3
EXTERNAL_NETWORKS: 192.168.1.0/24
ISOLATED_ADDRESS: 10.8.0.1
ISOLATED_INTERFACE: wg0
ISOLATED_NETWORK: 10.8.0.0/24
PUBLIC_CONTACT_EMAIL: root@pirogue.local
PUBLIC_DOMAIN_NAME: pirogue.local
PUBLIC_EXTERNAL_ADDRESS: 185.199.111.153
SYSTEM_HOSTNAME: pirogue
SYSTEM_OPERATING_MODE: wireguard
WIFI_COUNTRY_CODE: FR
WIFI_PASSPHRASE: superlongkey
WIFI_SSID: PiRogue
```

| Variable | Description |
|----------|-------------|
| `SYSTEM_OPERATING_MODE` | The [operating mode](/docs/explanation/pirogue/operating-modes) of the PiRogue, for instance `wireguard` for the VPN mode |
| `SYSTEM_HOSTNAME` | Hostname of the PiRogue. The dashboard is also served at `https://<SYSTEM_HOSTNAME>.local/dashboard` |
| `DASHBOARD_PASSWORD` | Password of the user `admin` of the dashboard, generated at the installation |
| `EXTERNAL_INTERFACE`, `EXTERNAL_ADDRESS`, `EXTERNAL_NETWORKS` | Interface connected to the Internet, its address and its networks. The dashboard is served at `https://<EXTERNAL_ADDRESS>/dashboard` |
| `ISOLATED_INTERFACE`, `ISOLATED_ADDRESS`, `ISOLATED_NETWORK` | Interface of the isolated network, on which the analyzed devices are connected, its address and its network |
| `ENABLE_DHCP` | Whether the PiRogue serves DHCP on the isolated network |
| `WIFI_SSID`, `WIFI_PASSPHRASE`, `WIFI_COUNTRY_CODE` | Wi-Fi network, in access point mode. The passphrase is generated at the installation |
| `ENABLE_PUBLIC_ACCESS`, `PUBLIC_DOMAIN_NAME`, `PUBLIC_CONTACT_EMAIL`, `PUBLIC_EXTERNAL_ADDRESS` | Public access from the Internet, see [Make the PiRogue accessible from the Internet](/docs/how-to/pirogue/configure-pirogue#make-the-pirogue-accessible-from-the-internet) |

## Default generated secrets

| Secret | Command |
|--------|---------|
| Wi-Fi passphrase | `pirogue-admin-client wifi get-configuration` |
| Dashboard password | `pirogue-admin-client dashboard get-configuration` |
| Remote administration token | `pirogue-admin-client access get-administration-token` |
