# Hardware

The PiRogue runs on a bare Raspberry Pi. No add-on board (HAT) or custom case is supported.

## Supported Raspberry Pi models

| Model | Support |
|-------|---------|
| Raspberry Pi 3 Model B | Supported, with limited services <sup>1</sup> |
| Raspberry Pi 3 Model B+ | Supported, with limited services <sup>1</sup> |
| Raspberry Pi 4 Model B - 1GB | Supported, with limited services <sup>1</sup> |
| Raspberry Pi 4 Model B - 2GB | Supported, with limited services <sup>1</sup> |
| Raspberry Pi 4 Model B - 4GB | Supported |
| Raspberry Pi 4 Model B - 8GB | Supported |
| Raspberry Pi 5 | Experimental <sup>2</sup> |

<small>
<sup>1</sup> Suricata is automatically disabled on systems with less than 2.5GB of RAM.<br/>
<sup>2</sup> Download the experimental PiRogue OS version for Raspberry Pi 5 from the download page.
</small>

## Required parts

| Part | Specification |
|------|---------------|
| Raspberry Pi | One of the [supported models](#supported-raspberry-pi-models) |
| Power supply | Appropriate for the model, such as the official Raspberry Pi power supply |
| Micro SD-card | 32GB for regular use, 64GB for long runs or several devices. Application Performance Class 1 (A1) and Speed Class 10 recommended |
| Ethernet cable | Cat. 5 or better, to connect the PiRogue to your network |

## Performance limits

* Up to 2-3 devices connected to the Wi-Fi access point at the same time.
* 5 days of network traffic history stored by default.
* The memory limit of Suricata is set in `/etc/systemd/system/suricata.service.d/override.conf`.

To set up a PiRogue on a Raspberry Pi, see [Install a PiRogue](/docs/how-to/pirogue/install-pirogue) or follow the tutorial [Your first PiRogue on a Raspberry Pi](/docs/tutorials/pirogue-on-a-raspberry-pi).
