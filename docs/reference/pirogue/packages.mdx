# Packages

Every feature of the PiRogue is a Debian package. There is one package repository per PiRogue version:

* PiRogue 3.x runs on Debian 13. Its packages are in the [Debian 13 package repository](https://pts-project.org/debian-13/).
* PiRogue 2.x runs on Debian 12. Its packages are in the [Debian 12 package repository](https://pts-project.org/debian-12/).

The source of most packages is in the [`deb-packages`](https://github.com/PiRogueToolSuite/deb-packages) repository. To understand why the PiRogue is built this way, see [Operating system and packaging](/docs/explanation/pirogue/operating-system).

| `pirogue-admin-web` | 3.0.0 | [Admin web interface](/docs/reference/pirogue/admin-web-interface) |
| `python3-pirogue-admin-api` | 3.0.0 | API of the administration tool |

| `pirogue-dashboard` | 3.0.0 | [Dashboard](/docs/reference/pirogue/dashboard) |

| `pirogue-tools` | 3.0.0 | Other necessary software, such as Frida |

| `pirogue-octopus` | 1.2.0 | Dynamic analysis framework for Android apps |

| `pirogue-archive-keyring` | 0.2 | Signing keys of the PiRogue package repository |
| `pirogue-telemetry` | 1.0.1 | [Telemetry](/docs/reference/pirogue/telemetry). Recommended by `pirogue-base`, not required |

## Configuration files managed by the packages

Upgrading the packages overrides changes made by hand in these files.

### PiRogue 1.x

| File | Package |
|------|---------|
| `/etc/hostapd/hostapd.conf` | `pirogue-ap` |
| `/etc/dnsmasq.conf` | `pirogue-ap` |
| `/etc/dhcpcd.conf` | `pirogue-ap` |
| `/etc/iptables/rules.v4` | `pirogue-ap` |
| `/etc/iptables/rules.v6` | `pirogue-ap` |
| `/etc/suricata/suricata.yaml` | `pirogue-eve-collector` |
| `/etc/grafana/grafana.ini` | `pirogue-dashboard` |
| `/etc/grafana/provisioning/datasources/datasources.yml` | `pirogue-dashboard` |
| `/etc/grafana/provisioning/dashboards/grafana_dashboards.yml` | `pirogue-dashboard` |
| `/var/lib/grafana/dashboards/pirogue-dashboard.json` | `pirogue-dashboard` |
| `/var/lib/grafana/dashboards/pirogue-flow-details-dashboard.json` | `pirogue-dashboard` |

### PiRogue 2.x

The configuration is generated by `pirogue-admin` from the following files, which upgrades try to preserve:

* `/var/lib/pirogue/admin/config.yaml`
* `/var/lib/pirogue/admin/wireguard/config.yaml`, in VPN mode
* `/var/lib/pirogue/admin/client.yaml`
* `/var/lib/pirogue/admin/daemon.yaml`
* `/var/lib/pirogue/admin/pirogue-external-exposure/fullchain.pem`
* `/var/lib/pirogue/admin/pirogue-external-exposure/privkey.pem`
