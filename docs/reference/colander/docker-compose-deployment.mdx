# Docker Compose deployment

Reference for a Colander deployed with [Colander quick deploy](https://pts-project.org/colander-ansible/), the `docker` folder of the [`colander-ansible`](https://github.com/PiRogueToolSuite/colander-ansible/tree/feat/compose-standalone) repository. To deploy one, see [Deploy Colander with Docker Compose](/docs/how-to/colander/deploy-with-docker-compose).

## Compose files

| File | Description |
|------|-------------|
| `compose-init.yml` | Bootstraps a minimal `.env` file with randomly generated secrets. Run it once, before anything else. |
| `compose.yml` | The whole stack, with Let's Encrypt certificates. Base file for production deployments. |
| `compose-dev.yml` | Includes `compose.yml` and overrides some services: generates a self-signed certificate in `./data/traefik/certs/self-signed/cert.pem` and exposes the Traefik dashboard. |
| `compose-colander.yml` | Colander alone, with its database, object storage, search engine and cache. |
| `compose-threatr.yml` | Threatr alone. |
| `compose-mandolin.yml` | Mandolin alone, with Apache Tika and ClamAV. |
| `compose-cyberchef.yml` | CyberChef alone. |
| `compose-playwright.yml` | Playwright, which takes the screenshots of URLs and captures their HAR files. Optional: included by `compose.yml`, add it with `-f` when you start components one by one. |
| `.env.example` | All the available settings, commented. |

## Addresses

| Service | Local address | Hostname address |
|---------|---------------|------------------|
| Colander | `http://localhost:5000` | `https://colander.local:4443` |
| Threatr | `http://localhost:5001` | `https://threatr.local:4443` |
| Mandolin | `http://localhost:5002` | `https://mandolin.local:4443` |
| CyberChef | `http://localhost:5003` | `https://cyberchef.local:4443` |
| Traefik dashboard, `compose-dev.yml` only | `http://localhost:8080` | `http://traefik.local:8080` |

The hostname addresses require the hostnames to be added to the line starting with `127.0.0.1` in `/etc/hosts`. The administration panels of Colander and Threatr are served at `admin/` by default.

## Services

| Service | Compose file |
|---------|--------------|
| `colander-front`, `colander-worker`, `colander-postgres`, `minio` | `compose-colander.yml` |
| `threatr-front`, `threatr-worker`, `threatr-postgres` | `compose-threatr.yml` |
| `mandolin`, `tika`, `clamav` | `compose-mandolin.yml` |
| `cyberchef` | `compose-cyberchef.yml` |
| `playwright` | `compose-playwright.yml` |
| `traefik`, `elasticsearch`, `redis`, `watchtower` | `compose-base.yml`, shared by the other files |

See [Services](/docs/reference/colander/services) for the role of each service.

## Configuration

The settings are read from the `.env` file in the `docker` folder. `compose-init.yml` creates it with the required secrets. All the other settings have defaults and are documented in `.env.example`. The main ones are:

| Setting | Description |
|---------|-------------|
| `COLANDER_DJANGO_SECRET_KEY`, `THREATR_DJANGO_SECRET_KEY` | Secret keys of Colander and Threatr. Required, generated by `compose-init.yml`. |
| `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY`, `MINIO_ROOT_USER`, `MINIO_ROOT_PASSWORD` | Credentials of the object storage. Required, generated by `compose-init.yml`. |
| `COLANDER_IMAGE_VERSION`, `THREATR_IMAGE_VERSION`, `MANDOLIN_IMAGE_VERSION`… | Versions of the Docker images. The PTS images have two main tags: `main`, the latest release, and `next`, the staging version. The `.env` file created by `compose-init.yml` sets `COLANDER_IMAGE_VERSION=next`. |
| `COLANDER_FQDN`, `THREATR_FQDN`, `CYBERCHEF_FQDN`, `TRAEFIK_DASHBOARD_FQDN` | Domain names of the services. Default to `colander.local`, `threatr.local`, `cyberchef.local` and `traefik.local`. |
| `COLANDER_BASE_URL`, `THREATR_BASE_URL`, `CYBERCHEF_BASE_URL`, `MANDOLIN_BASE_URL` | Addresses the services use to reach each other. |
| `TRAEFIK_CERTIFICATESRESOLVER_LETSENCRYPT_ACME_EMAIL` | Email address passed to Let's Encrypt. |
| `TRAEFIK_HTTP_BINDING`, `TRAEFIK_HTTPS_BINDING`, `TRAEFIK_DASHBOARD_BINDING` | Addresses the reverse proxy listens on. Default to `127.0.0.1:8000`, `127.0.0.1:4443` and `127.0.0.1:8080`. |
| `COLANDER_DJANGO_ADMIN_URL`, `THREATR_DJANGO_ADMIN_URL` | Paths of the administration panels. Default to `admin/`. |
| `ELASTICSEARCH_ES_JAVA_OPTS_XMS`, `ELASTICSEARCH_ES_JAVA_OPTS_XMX` | Memory allocated to Elasticsearch. |
| `*_VOLUME_PATH` | Docker volumes or paths where the data is stored. |
| `DOCKER_SOCKET_PATH` | Path of the Docker socket, for instance `/run/user/1000/docker.sock` with rootless Docker. |
| `DOCKER_LOG_DRIVER` | Logging driver of the containers, such as `json-file` (default), `journald` or `syslog`. |
| `TRAEFIK_LOG_LEVEL` | Log level of the reverse proxy. `ERROR` by default, `TRACE` with `compose-dev.yml`. |
| `TRAEFIK_ACCESSLOG_ENABLED` | Logs the incoming requests. Enabled by default. |
