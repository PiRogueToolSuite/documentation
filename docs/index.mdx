# PiRogue Tool Suite documentation

The PiRogue Tool Suite (PTS) is an open-source set of tools for digital forensics and network traffic analysis, designed for civil society organizations: the **PiRogue** network probe, the **Colander** investigation platform, and the **Threatr** and **Mandolin** services that enrich its evidence.

This documentation is organized in four sections. Each one answers a different need, so pick the one that matches what you are trying to do right now.

New to the PiRogue Tool Suite? Read [what it is](/docs/explanation/pts/about), then follow a [tutorial](/docs/tutorials).

## Who this documentation is for

The documentation is written for people with some experience of networks and Linux: you should be comfortable with the command line of your operating system. Some understanding of security concepts, of Internet protocols and of incident response helps, but is not required to follow the tutorials. Experienced security professionals, network administrators and system administrators will find the details they need in the reference.
