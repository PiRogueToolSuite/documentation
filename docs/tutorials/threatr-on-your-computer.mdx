# Try Threatr on your computer

In this tutorial, we will run Threatr locally, create an administrator and an API key, and ask Threatr about a file hash.

## What you need

Docker with Docker Compose, `curl` and `openssl`.

## Start Threatr

Copy and paste the following block in a terminal. It downloads the configuration, generates new secrets, starts Threatr, creates an administrator and creates an API key.

```bash title="Deploy Threatr locally"
mkdir -p threatr && cd threatr
BASE=https://raw.githubusercontent.com/PiRogueToolSuite/threatr/refs/heads/main/deployment
curl -fsSLO $BASE/.env
curl -fsSLO $BASE/threatr-local.yml

# Generate new secrets
sed -i "s|^DJANGO_SECRET_KEY=.*|DJANGO_SECRET_KEY=$(openssl rand -hex 32)|; s|^POSTGRES_PASSWORD=.*|POSTGRES_PASSWORD=$(openssl rand -hex 24)|" .env

# Start Threatr and wait until it answers
docker compose -f threatr-local.yml up -d
until curl -s -o /dev/null http://127.0.0.1:9080/admin/login/; do sleep 2; done

# Create the administrator and an API key
ADMIN_PASSWORD=$(openssl rand -hex 12)
docker compose -f threatr-local.yml run --rm -e DJANGO_SUPERUSER_PASSWORD="$ADMIN_PASSWORD" \
  threatr-local-front python manage.py createsuperuser --noinput --username admin --email admin@localhost
API_KEY=$(docker compose -f threatr-local.yml run --rm threatr-local-front python manage.py drf_create_token admin | awk '/Generated token/{print $3}')

echo "Administration panel: http://127.0.0.1:9080/admin (user: admin, password: $ADMIN_PASSWORD)"
echo "API key: $API_KEY"
```

:::note

On macOS, replace `sed -i` with `sed -i ''`.

:::

## Ask Threatr a question
With the API key displayed at the end of the block, list the available integrations:

```bash
curl -s http://127.0.0.1:9080/api/modules/ -H "Authorization: Token $API_KEY"
```

Every integration is listed with `"configured": 0`: no third-party service is connected yet. Now ask for threat intelligence about the SHA256 of a file:

```bash
curl -s -X POST http://127.0.0.1:9080/api/request/ \
  -H "Content-Type: application/json" -H "Authorization: Token $API_KEY" \
  -d '{"super_type": "observable", "type": "sha256", "value": "854774a198db490a1ae9f06d5da5fe6a1f683bf3d7186e56776516f982d41ad3", "force": false}'
```

Threatr answers, but with little information: it only returns data from the services you connect to it, and none is connected yet.

## Stop Threatr

To stop Threatr, run `docker compose -f threatr-local.yml stop`. To remove it with all its data, run `docker compose -f threatr-local.yml down -v`.
